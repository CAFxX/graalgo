# L34 (P1-31) — GoNet.STATES entries are never evicted (socket leak)

## Issue

`internal/backend/interop/src/main/java/graalgo/p3net/GoNet.java` keeps a static
`STATES` map (`ConcurrentHashMap<Long, SockState>`, line ~172) with one entry per
socket cookie, inserted at `STATES.put` in `socket()` (~427) and in `accept()`
(~542). There was **no `STATES.remove` anywhere**. `GoOs.close(cookie)` removed the
handle from `HANDLES` and evicted netpoller state via `GoNetpoll.evictForClose`,
but left the `SockState` behind — so long-running accept loops grew the static map
without bound (a socket leak; unbounded memory growth in a static map).

## Fix design

Two options from the brief: (a) evict in `GoOs.close` for `KIND_SOCKET` handles next
to the `GoNetpoll.evictForClose` call, or (b) add `GoNet.evictSocket(cookie)` and
call it there. Implemented (a)+(b) together:

- `GoNet.evictSocket(long sockCookie)` — new public static method, a thin wrapper
  around `STATES.remove(sockCookie)`. Idempotent (plain `ConcurrentHashMap.remove`).
- `GoOs.close(Object)` — inside the existing `if (handle.kind == KIND_SOCKET)` block,
  next to `GoNetpoll.evictForClose(cookie)`, calls `GoNet.evictSocket(cookie)`.

Audit notes (verified against the tree):

1. **Exact targeting** — the call sits inside `if (handle.kind == KIND_SOCKET)`;
   regular files, dirs, and other handle kinds are untouched (no over-eviction).
2. **Thread-safety** — `STATES` is a `ConcurrentHashMap`; `remove` is atomic.
3. **Complete coverage** — both `STATES.put` sites funnel through `GoOs.close`:
   `socket()` cookies are registered via `GoOs.registerSocketChannel` with
   `KIND_SOCKET`, and `accept()` cookies likewise (`registerSocketChannel(...,
   KIND_SOCKET)`), so accepted sockets are evicted too.
4. **Single close path** — `GoOs.close` is the only handle-close funnel (the
   second close of an already-closed cookie returns `-EBADF` before reaching the
   eviction, since `HANDLES.remove` returns null).

## Test

New `internal/backend/interop/src/test/java/graalgo/p3net/GoNetStatesEvictTest.java`
(loopback-only, no scheduler needed), registered in `IfaceTestRunner`:

- `testStatesEvictedOnSocketClose` — opens 8 stream+datagram sockets, asserts
  `STATES.size() == 8` via reflection, closes all via `GoOs.close`, asserts
  `STATES.size() == 0`.
- `testAcceptedSocketEvictedOnClose` — listener + client + accepted = 3 entries,
  closes all three, asserts 0 (covers the `accept()` insert path).
- `testDoubleCloseDoesNotRecreateState` — close, then close again (returns nonzero),
  asserts `STATES` stays empty (idempotency).
