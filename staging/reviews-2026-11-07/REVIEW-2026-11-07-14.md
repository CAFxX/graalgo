### Docs / CI / scripts

#### N-P1-1 — `build.sh check` vendoring diff gate cannot fail (live in per-push CI) — P1
- **Files:** `internal/frontend/build.sh:56` (`set -eu` at :13; `#!/bin/sh` = dash).
- **What:** `diff -r "$GOROOT_DIR/src/go" "$PWD/go" && echo "vendored tree byte-identical …"`. Under `set -e`, a failing command inside an `&&` list (other than the last) does **not** exit the shell — so when the vendored tree diverges from GOROOT, the `&& echo` is skipped and the script continues to the validator and exits 0. **Mechanism verified by execution:** the equivalent dash snippet in `/tmp` (`set -eu` + failing `diff -r … && echo`) printed the post-diff line and exited 0.
- **Why:** the byte-identity gate exists precisely to catch a local patch to `./go` (header comment, `VENDORING.md`), and it is wired into per-push CI via `make all` → `make check` → `build.sh check`. A diverged vendored tree would pass CI silently. Same failure class as R-08.
- **Suggested fix:** split the gate: `diff -r "$GOROOT_DIR/src/go" "$PWD/go" || exit 1` (then echo on success), or capture `rc=$?` and fail on non-zero.
- **Lane:** L-BUILDSH.

[Correction by lane rev1107-14-stdlibasm, 2026-11-07: the review as filed counted 18, including files build tags exclude (`syscall/asm_unix_amd64.s` is BSD-only; `simd/dummy.s` is `goexperiment.simd`-gated).]

- **Files:** `internal/frontend/synth_crypto_tls.go:723` (`Conn.Handshake`), `:748-750`.
