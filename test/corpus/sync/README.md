# P3-M2b `sync` corpus

Go programs exercising the P3-M2b `sync` Go bindings (ADR-0002),
differential vs stock gc 1.27.1. Ports every leg of the Java-level
`SyncStressTest` (`phases/phase2/src/test/java/graalgo/runtime/sync/`),
discharging the P2-M8 re-test trigger.

## Programs

| Program | Covers | Java leg |
|---|---|---|
| `sy00_construction.go` | all construction forms (`var`, `:=`, `&`, `new`), package-level var, `defer` + `syncop` | — |
| `sy01_mutex_exclusion.go` | 32 goroutines × 1000 increments; exact final counter | `testMutexExclusion` |
| `sy02_mutex_defer.go` | deferred unlock across goroutines | — |
| `sy03_mutex_unlock_misuse.go` | unlock-of-unlocked: message parity (panic, ADR-0002 D4) | `testMutexUnlockOfUnlockedPanics` |
| `sy04_rwmutex.go` | 16 readers × 500 + 2 writers × 100; exact value, no torn reads | `testRWMutex` |
| `sy05_rwmutex_runlock_misuse.go` | RUnlock-of-unlocked: message parity (panic, ADR-0002 D4) | — |
| `sy06_waitgroup.go` | 50 workers + `Wait`; exact count | `testWaitGroup` |
| `sy07_waitgroup_reuse.go` | `Add`/`Done`/`Wait` reuse across 3 rounds | — |
| `sy08_waitgroup_negative.go` | negative counter: `panic: sync: negative WaitGroup counter` (full gc parity) | `testWaitGroupNegativePanics` |
| `sy09_waitgroup_zero_wait.go` | zero-counter `Wait` returns immediately | `testWaitGroupZeroAwaitImmediate` |
| `sy10_once.go` | 32 racers; exactly-once + no re-run | `testOnce` |
| `sy11_once_panic_done.go` | panicking `Do` func counts as done; panic propagates and is recoverable | — |
| `sy12_defer_recv_reassign.go` | `defer m.Unlock()` uses `&m`: reassigned receiver unlocks the current (unlocked) object → misuse panic | — |

The cap-1 leg (`testMutexCapOne`) is the same program as `sy01` run with
`--gmp=1` (the in-flight cap is a launcher flag, not a program property).

## Files per program

- `syNN_*.go` — the program (deterministic: only aggregates on stdout).
- `syNN_*.expected` — gc stdout (regenerated by `regen.sh`; empty for
  panic programs).
- `syNN_*.panic` — for panic programs: the expected **graalgo** first
  stderr line. For `sy03`/`sy05` this is `panic: sync: ...` where gc
  prints `fatal error: sync: ...` (ADR-0002 D4 scoped divergence: same
  message text, same exit code 2); gc's own line is kept in
  `syNN_*.panic.gc` for the record.

## Running

```bash
./regen.sh               # regenerate .expected/.panic.gc from gc 1.27.1
./run_differential.sh    # gc binary vs graalgo-sync-run: stdout bytes,
                         # exit codes, first stderr line (panic programs)
```

The differential runner filters the known JVM `Unsafe` warnings on
stderr (harness noise, cf. `p3frontend/DESIGN.md` §7) and compares the
first remaining stderr line for panic programs.
