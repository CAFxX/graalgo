# `compress/bzip2` wave-3 corpus

Differential corpus for the synthetic `compress/bzip2` package (pure-Go
port of gc 1.27.1, value-identical to gc).

## Scope boundary

The whole package is in scope: `NewReader`, `Reader` (`Read`). bzip2
has no writer in the stdlib; test blobs are generated by an independent
encoder (Python's `bz2`, compresslevel 9) and embedded as byte
literals — every blob was verified to decompress correctly under gc
1.27.1 before pinning. No `.scopelimited` programs.

## Programs

- `00_decompress.go` — decompress pinned blobs (empty, text, zeros,
  64KB text, incompressible random); output byte-identical to raw.
- `01_streaming.go` — 1-byte reads; 5-byte-chunk source; concatenated
  members (first member decompresses).
- `02_corrupt.go` — truncated -> `io.ErrUnexpectedEOF`; bad magic ->
  "bzip2 data invalid: bad magic value"; bit-flipped block ->
  "bzip2 data invalid: block checksum mismatch".
